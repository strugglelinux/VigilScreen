# VigilScreen 操作指南

安装依赖、下载通用模型后启动一体窗口。Apple Silicon 快速启动见 [README](../README.md)，Intel Mac 和 Windows 见 [平台说明](PLATFORMS.md)。源码和安装包使用不同的数据位置，修改源码不会更新已安装应用。

## 开始监控

应用启动后摄像头保持关闭，在“实时监测”页点击“开始监控”后才加载模型和开启采集。

- “全部人脸（不指定身份）”：不需要个人身份模型，检查画面中所有可判断的人脸。
- 指定身份：选择已经训练并登记的身份，仅该身份可触发命中。
- “过滤目标”：选中的身份不做视线检查，不触发命中；过滤优先于目标选择。全员模式启用身份过滤时，也需要身份模型。

切换目标会先停止旧目标检测，应用选择后从新帧恢复；同一监控会话复用摄像头和模型。首次从全员切换到身份模式可能需要加载身份模型，可观察“正在切换”提示。切换期间不触发命中，尚未提交的旧范围截图会丢弃。点击“取消切换并暂停”可停止。

展开目标下拉菜单时，视频和状态暂缓重绘，后台检测继续。菜单收起后显示最新画面。侧栏内容较长时，可用滚轮或右侧滚动条查看；“开始 / 暂停”和“退出并关闭摄像头”固定在底部。

macOS 命中时在顶部菜单栏显示 `Peek N · 全员` 或 `Peek N · 指定：身份`；相邻命中间隔不超过 10 秒时累计计数。Windows 在窗口中显示命中及截图信息。持续注视通常只触发一次，连续 3 个处理帧不满足条件后可再次触发。

## 镜头与屏幕视线校准

正脸朝向和双眼视线都需要满足条件。仅检测到身份、脸朝正前方，都不代表一定命中。

1. 先开始监控，确认画面中有清晰目标脸。
2. 校准时仅保留一张可用目标脸，睁眼看向摄像头或常看的屏幕位置。
3. 点击“校准镜头视线 · 5 帧”或“校准屏幕中心 · 5 帧”，稍候开始采样，等待成功提示。
4. 移开视线，再重新看向对应位置验证。

需要覆盖更多屏幕位置时，先完成中心校准，再点击“扩展屏幕边角 · 5 帧”，保持头部稳定并注视一个边角；可对其他常看的边角重复操作，最多保留中心及最近 8 个边界参考。扩展保留已有位置的接受范围，不需要一次快速扫视整个屏幕。

两种参考可分别校准，任一种通过均可触发。校准采样不稳定会自动重采，超时则保留先前参考。闭眼、双眼分辨率不足或出现多个可用候选时不会继续拼接采样。正常监控仍单帧通过即可命中，不等待 5 帧；5 帧只用于校准。

校准期间不命中；切换目标、刷新模型或重新开始监控后应重新校准。人脸位置或距离明显变化也应重新校准。全员模式使用位置约束防止明显不同位置的人脸借用参考，但位置不是身份识别；需要限定人员时请选择已登记身份。该算法不是精确眼动仪，也不能保证覆盖未校准屏幕位置，详见 [视线算法说明](GAZE_ALGORITHM.md)。

截图保存在数据根目录的 `screenshots/`，红框标识该帧满足命中条件的人脸。“最近截图”显示文件名，“复制保存信息”可取得完整路径。

## 图片手动标记

进入“标记 · 训练 · 验证 → 图片手动标记”：

1. 设置标记输出目录，默认是 `data/labeled/`。
2. 点击“导入图片目录（含子目录）”。原图目录不能是输出目录或其内部目录。
3. 在左侧画面拖动鼠标，框选需要保存的区域；不画框则保存整图。
4. 选择已有类别，或直接输入新类别 / 身份名称。
5. 设置“最长边”：默认 256 像素，0 表示不缩放。点击“保存并下一张”。

原图不修改，裁剪副本按 `<输出目录>/<类别>/` 保存。“清除选框 · 使用整图”取消裁剪；“上一张”和“跳过 / 下一张”用于浏览。可左右拖动预览与侧栏之间的分隔条；预览放大只改变显示，不改变原图坐标或保存尺寸。

类别下拉框合并当前输出目录的类别文件夹、标记记录和已登记身份。两个标记页共用选项，启动、展开下拉框、修改输出目录及保存后都会刷新；刷新保留正在输入的新名称。

## 摄像头标记

进入“摄像头标记”，设置摄像头编号并点击“打开摄像头”。如果监控摄像头仍在释放，请稍后再打开；不要同时在两个页面占用同一摄像头。

1. 在实时画面按下鼠标时自动冻结，继续拖动框选区域；也可点击“冻结画面”。
2. 填写类别、设置最长边，点击“保存标记”。
3. 保存成功后继续预览；也可点击“继续预览”放弃当前冻结选区。

裁剪结果按类别保存，并归档到输出目录旁的 `<输出目录名称>_captures/`。默认对应 `data/labeled_captures/`；该归档保存的是已裁剪、缩放的采集图，不是整张摄像头原始帧。关闭摄像头后，已冻结画面仍可继续标记。

两个页面的“用于训练 →”会把当前输出目录填入训练数据目录，并切换到可视化训练页，不会直接启动训练。

## 训练与身份登记

类别出现在标记下拉框中，仅代表存在材料或记录；需要完成“开始训练并登记身份”，该身份才可用于指定身份监控。

在“可视化训练”中确认材料目录和模型输出目录：

- 推荐按身份子目录组织图片，选择其上层目录。
- 单人平铺材料填写“单人材料名称”；也支持显式 `train/<身份>/`、`val/<身份>/` 划分。
- 每类最低 4 张；划分后至少 3 张训练图可提取唯一人脸特征。推荐每人 20 张以上，覆盖不同光线、角度和距离，避免连续重复截图充数。

点击“开始训练并登记身份”后，查看进度、分类曲线和训练输出。上下拖动曲线与日志之间的分隔条可调整高度，“放大日志”或“均分”可快速调整，日志支持横向和纵向滚动。训练或验证期间不要修改正在使用的标记材料。

训练设备选择 `auto` 即可；无可用加速设备时使用 CPU，Intel Mac 自动选择默认使用 CPU。训练成功后更新当前模型入口，返回实时监测页选择身份，再手动开始监控。失败或停止保留之前已发布的模型。

CNN 分类曲线不等于身份匹配效果。单类别 softmax 恒为 100%，交叉熵可以为 0；实时身份使用 SFace 登记特征，必须另看身份验证结果。

## 验证身份效果

在“身份效果验证”选择模型输出目录。外部验证目录留空时使用训练时保留的验证原图；提供新材料时，按已知身份和 `unknown/` 陌生人分目录。平铺图片需填写预期身份。

点击“运行身份验证”，检查逐图结果、相似度、失败原因和训练重复标记。已知身份匹配率包含失败或不可用验证图；陌生人误接受率只使用可用的唯一人脸样本，无样本时不报告。使用未参与训练的新图片评估更有意义。

验证衡量身份匹配，不衡量是否看向摄像头。视线效果需在目标摄像头、距离、光线和屏幕位置下实际验证。

## 数据、初始化与常见问题

默认数据位置：

| 运行方式 | 数据根目录 |
| --- | --- |
| 源码 | 项目目录 |
| macOS 独立应用 | `~/Library/Application Support/VigilScreen/` |
| Windows 独立应用 | `%LOCALAPPDATA%\VigilScreen\` |

`VIGILSCREEN_DATA_DIR` 可覆盖根目录；标记和训练页也可单独指定输出目录。使用 `vigil_app.py` 或独立包启动时，日志位于根目录的 `logs/`；通过终端直接运行 `main.py` 的输出通常显示在终端。

“操作 → 初始化…”会先弹出确认，再停止后台任务，清空当前应用管理的训练、身份、验证、截图及选择 / 校准信息。通用视觉模型和项目外的原图、模型、备份保留。初始化不能撤销，需要的数据请先备份。

| 情况 | 检查方法 |
| --- | --- |
| 类别下拉框没有预期名称 | 检查当前标记输出目录；展开下拉框刷新。材料不在该目录时，选择正确输出目录。 |
| 监控目标列表没有新身份 | 确认训练和登记成功，加载对应 `active_profile.json`，或刷新模型 / 身份样本。标记一个类别不会自动完成登记。 |
| 选中身份但没有命中 | 检查过滤名单、身份匹配、脸部朝向、双眼清晰度及屏幕校准；被过滤的人不会命中。 |
| 摄像头打不开 | 检查编号、系统摄像头权限及其他应用占用；在两个页面之间切换时等待设备释放。 |
| 底部按钮或更多设置看不到 | 使用侧栏滚动条；开始 / 暂停及退出固定在底部。标记页可拖动左右分隔条，训练页可拖动上下分隔条。 |
| 安装包没有出现最新修改 | 源码修改不影响旧安装包，需要在对应系统和架构重新构建，完成自检后替换。 |

本机依赖和模型检查可运行 `python check_environment.py --models`；该检查不打开真实摄像头。平台已验证范围、安装和打包步骤见 [PLATFORMS.md](PLATFORMS.md) 与 [DISTRIBUTION.md](../DISTRIBUTION.md)。
